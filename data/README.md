# Project Data Inventory and Recovery Guide

## Directory roles

- `data/raw/` contains retained source snapshots. Do not edit these files manually.
- `data/reference/` contains municipal boundary files used for maps and spatial checks.
- `data/processed/` contains outputs generated by analysis scripts. Do not edit processed outputs manually; rerun the producing script instead.

### Pedestrian filename warning

Do not infer the observation years from `pedestrian_counts_2019_2024.csv`, and do not rename or replace it during reproduction. The historical filename is retained because the pipeline, checksum manifest and recorded outputs refer to it. The retained file actually covers **19 August 2024 to 15 August 2026**: 2025 is the primary analysis year, 2024 is an incomplete comparison period, and 2026 is used only for coverage diagnostics. A newly downloaded portal export is a different snapshot unless its SHA-256 matches the value above.

## Restore missing inputs

1. Clone the repository. All currently tracked raw and reference snapshots are restored by Git except `data/raw/microclimate_sensors.csv`.
2. Download the exact microclimate snapshot from the verified project Release asset: <https://github.com/XINLEI-LUO/ETC5543_noise_complaints/releases/download/microclimate_sensors_data_snapshot_2026_08/microclimate_sensors.csv>. Because the repository is currently private, an anonymous request returns 404. Authenticate with GitHub CLI and run `gh release download microclimate_sensors_data_snapshot_2026_08 --repo XINLEI-LUO/ETC5543_noise_complaints --pattern microclimate_sensors.csv --dir data/raw`.
3. Save it as `data/raw/microclimate_sensors.csv` without opening and resaving it in spreadsheet software.
4. Verify the SHA-256 before running analysis.
5. If another raw or reference file is missing from Git, download the current official export shown above, but treat it as a new snapshot. Record its download date, actual range and SHA-256; do not claim that it reproduces the retained snapshot unless its checksum matches.

To confirm that the smaller required snapshots came from the clone rather than an untracked local copy, run:

```sh
git ls-files --error-unmatch data/raw/pedestrian_counts_2019_2024.csv data/raw/pedestrian-counting-system-sensor-locations.csv data/raw/bars-and-pubs-with-patron-capacity.csv data/raw/cafes-and-restaurants-with-seating-capacity.csv data/raw/business-establishments-with-address-and-industry-classification.csv data/reference/melbourne_municipal_boundary.geojson data/reference/melbourne_municipal_boundary_coordinates.csv
```

`data/raw/microclimate_sensors.csv` is intentionally Git-ignored because it exceeds GitHub's normal file-size limit. Its recoverability depends on the Release asset and the checksum, not on `git status`.

Windows PowerShell:

```powershell
Get-FileHash data/raw/microclimate_sensors.csv -Algorithm SHA256
```

macOS or Linux with `sha256sum`:

```sh
sha256sum data/raw/microclimate_sensors.csv
```

macOS fallback:

```sh
shasum -a 256 data/raw/microclimate_sensors.csv
```

The result must be `85f784a66356cbc0eba0793d95faec8801627baf03485a3a15fb17c74e03eb01`.

## Zero and missing values

- Raw zero Noise readings are retained in the primary analysis because the source meaning of zero is unresolved. `analysis/noise_zero_value_sensitivity.R` provides a parallel analysis that excludes `Noise == 0` without changing the raw file or the primary outputs.
- Noise summaries use finite Noise values; missing source values are represented as `NA` in memory and blank fields in CSV outputs where scripts use `na = ""`.
- For spatial features, zero means the source loaded successfully and no qualifying record was found within the buffer.
- `NA` is retained for missing inputs or attributes, invalid coordinates, failed linkage, or cases where a defensible value cannot be calculated. Scripts stop on required-input failures rather than silently replacing failures with zero.

## Snapshot limitations

City of Melbourne portal datasets are updated over time. Dataset pages and current export URLs identify the source but do not reproduce an earlier snapshot unless a fixed asset or matching checksum is available. Except for the verified microclimate GitHub Release, no fixed snapshot URL is currently verified. Preserve the tracked raw/reference files and their checksums when exact reproduction is required.
