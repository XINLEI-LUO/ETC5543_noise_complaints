# Melbourne Noise Complaints Project

## Project overview

This is an ETC5543 group project investigating noise complaints in the City of Melbourne.

## Main research question

How do noise complaints vary across time and space in the City of Melbourne, and what factors are associated with these patterns?

## Current project status

The project is currently in its initial stage. The repository structure and analysis will be expanded later as the project develops.

## Repository structure

- `data/`: stores datasets used in the project.
- `meetings/`: stores the supervisor meeting agenda and future meeting records.
